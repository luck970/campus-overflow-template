## 二、角色认知

作为团队的 **Developer（开发者）**，我理解本角色的核心职责是：

1. 按 Sprint Backlog 与 DoD（完成的定义）完成所认领的功能开发；
2. 遵循团队的分支、提交与 Pull Request 规范，不直接向 `main` 推送；
3. 主动、认真地参与代码评审，也乐于接受他人对自己代码的评审；
4. 为自己编写的代码补充单元测试，保证质量；
5. 每日参加站会，如实同步进展与阻塞，遇到问题及时上报。

## 三、我的承诺

我郑重承诺：

- **履行角色职责**，认真完成认领的任务，不拖延、不甩锅；
- **遵守团队章程**，尊重团队价值观与各项约定；
- **保持透明**，遇到阻塞、延期或不懂的问题立即在团队内同步；
- **对事不对人**，在评审与协作中保持专业、友善；
- **持续学习**，主动帮助队友，也积极向队友学习，与团队共同成长。
